# CleanLock: Keyboard, Mouse & Touch Lock

**Lock everything. Clean anything.** — اقفل كل شيء ونظّف بأمان

CleanLock is a lightweight Windows app that temporarily locks your **keyboard, mouse, touchpad, touchscreen and pen** in one click, so you can clean your laptop or let kids watch a video without stray presses. Unlock with a simple hold-to-unlock shortcut.

🌐 **Website:** https://dwlbt.github.io/cleanlock/
🛒 **Microsoft Store:** https://apps.microsoft.com/detail/9NNJ7LW60MJ2 *(coming soon)*
🔒 **Privacy policy:** https://dwlbt.github.io/cleanlock/privacy.html

## Features
- One app for every input: keyboard, mouse, touchpad, touchscreen & pen
- Blocks touchpad 3- and 4-finger gestures and screen edge swipes
- **Cleaning mode** with an auto-unlock countdown
- **Kids** and **Watch** modes — your video keeps playing
- Hold-to-unlock shortcut (`Ctrl + Alt + U` for 2 seconds) — no accidental unlocks while wiping the keys
- Auto-unlocks when Windows is locked, the PC sleeps, or you press `Ctrl + Alt + Del`
- Restores brightness and mic after unlock
- Lightweight and offline — no data collected
- English & Arabic (full RTL), light & dark themes

## Safety
`Ctrl + Alt + Del` and the power button always work, so you can never get stuck.

## Notes
- Some manufacturer Fn keys (like brightness or airplane mode) are handled by the device hardware and can't be blocked. CleanLock restores brightness and mic when you unlock.
- Touchpad gesture blocking requires a recent version of Windows 11.

## Tech
C# · .NET 10 · WPF · MSIX · Windows low-level input hooks · Precision Touchpad gestures API
